# Stella Montis Night Raid Timer

A live countdown timer for the Stella Montis Night Raid event in [Arc Raiders](https://www.arcraiders.com/).

## Features

- Real-time countdown to the next Night Raid event on Stella Montis
- "TIME TO RAID" display when the event is active
- Auto-refreshes event data every 60 minutes
- Fallback to predicted schedule if API is unavailable
- Arc Raiders inspired visual theme

## Schedule

Stella Montis Night Raid occurs every 4 hours (1 hour duration):

| UTC |
|-----|
| 02:00 |
| 06:00 |
| 10:00 |
| 14:00 |
| 18:00 |
| 22:00 |
